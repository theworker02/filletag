Fill HTML/Markdown etag fragments safely for docs pipelines. Built as a tiny zero-dependency Node toolkit with a library API and a stdin-friendly CLI.

Usage

git clone https://github.com/theworker02/filletag.git
cd filletag
node src/cli.js --help
node --test
