# filletag

Fill HTML/Markdown etag fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/filletag/

## Install / run

```bash
git clone https://github.com/theworker02/filletag.git
cd filletag
node src/cli.js
node --test
```
